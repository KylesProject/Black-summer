# Black Summer Bushfires website

A static website. No build step needed.

## Files

index.html is the page.
style.css is the styling.
images is a folder you create for your photos and map.

## Adding photos

Create a folder named images next to index.html and add JPG files with these exact names.
Any file that is missing simply keeps its labelled placeholder box.

| File name | What it shows |
| --- | --- |
| red_skies.jpg | Red skies over burning bushland (top banner) |
| map.jpg | Map of the affected areas |
| eucalyptus_forest.jpg | Dry eucalyptus forest |
| pyrocumulonimbus.jpg | Pyrocumulonimbus cloud above a fire |
| wildlife.jpg | Wildlife harmed by the fires, such as a koala |
| mallacoota_beach.jpg | People gathered on the beach at Mallacoota |
| smoke_city.jpg | Smoke over Sydney or Canberra |
| kangaroo_island.jpg | Burned landscape on Kangaroo Island |
| firefighters.jpg | Firefighters at work during the fires |
| eucalypt_regrowth.jpg | Eucalypts sprouting from burned trunks |
| rebuilding.jpg | A town rebuilding after the fires |

Only use photos you own or have permission to use.

## Publishing on GitHub Pages

1. Create a new repository on GitHub.
2. Upload index.html, style.css and the images folder to the main branch.
3. Open Settings, then Pages.
4. Under Build and deployment, choose Deploy from a branch, pick main and the root folder, then Save.
5. After a minute or two your site is live at https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/
